# Проект: Fine-tuning Whisper для болгарской речи

Коротко о том, что сделано:
- Собрали и подготовили датасеты (реальные записи + синтетические данные).
- Сформировали манифесты и подготовили данные для обучения ASR.
- Дообучили Whisper и сохранили лучшие чекпоинты по качеству.
- Проверили качество модели на валидации и тесте.
