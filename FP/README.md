# Проект: дообучение Whisper для болгарской речи

Этот проект посвящён адаптации модели Whisper под распознавание болгарской речи. Основная цель — улучшить качество ASR для языка, для которого в открытом доступе доступно сравнительно мало качественных данных.

## Кратко о результате

В результате работы удалось значительно улучшить качество базовой модели Whisper small для болгарского языка. После дообучения модель стала работать заметно лучше, чем изначально, хотя всё ещё уступает более крупной модели Whisper large. Для обучения крупной модели у меня не хватило вычислительных ресурсов.

## Что было сделано

- Собраны и объединены доступные открытые датасеты по болгарской речи.
- Подготовлены аудио и текстовые данные для обучения и оценки.
- Выполнена очистка и нормализация транскрипций.
- Сформированы манифесты для обучения, валидации и теста.
- Добавлены дополнительные источники данных: аудиокниги, синтетические данные и псевдолейблы.
- Проведено дообучение Whisper на собранных данных.
- Сохранены лучшие чекпоинты и выполнена оценка качества модели.

## Какие были основные сложности

- Очень мало качественных открытых данных для болгарского ASR.
- Часть аудио и транскрипций имела низкое качество или несовпадения между текстом и записью.
- Нужна была тщательная очистка данных, иначе модель быстро начинала учиться на шуме.
- Синтетические данные помогли, но их качество оказалось неоднородным.
- Для экспериментов с более крупной моделью не хватало ресурсов, поэтому основной акцент был сделан на Whisper small.

## Оценка качества

На моей оценочной выборке качество модели заметно улучшилось:

- базовая Whisper small: примерно WER 0.52
- после дообучения: примерно WER 0.21

Для сравнения, Whisper large на той же задаче показывал ещё лучшее качество, но его дообучение потребовало бы значительно больше ресурсов.

## Что дальше

- собрать ещё больше качественных данных;
- улучшить фильтрацию и очистку датасета;
- попробовать более аккуратную балансировку реальных и синтетических данных;
- при наличии ресурсов — дообучить более крупную модель.
